ARCHITECTURE
Built for debugging, not custody.

      

      

        
01
Read
TraceLens calls public Solana JSON-RPC read methods such as getTransaction and getAccountInfo.

        
02
Normalize
Versioned and legacy response shapes are parsed defensively so missing metadata never crashes the UI.

        
03
Explain
Logs and instructions are reorganized into a chronological execution view with error context and deltas.

      

      
Safety model: no private keys, no wallet adapter, no signing, no transaction submission, no custody. TraceLens is a read-only developer utility.
